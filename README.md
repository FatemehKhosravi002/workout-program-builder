# 🏋️ Workout Program Builder

A workout program builder built with **Django, Django REST Framework, PostgreSQL, HTML, CSS, and JavaScript**.

### ✨ Features

- Create 2 or 3-day workout programs
- Search and select exercises by category
- Configure sets, reps, and notes
- Create 2-exercise supersets
- Preview workout programs
- Export programs as Persian PDF
- Add categories and exercises

### 🛠️ Tech Stack

**Backend:** Django, Django REST Framework, PostgreSQL  
**Frontend:** HTML, CSS, JavaScript  
**Deployment:** Gunicorn, WhiteNoise, Render
